# MetaTrace

MetaTrace is a browser-based file metadata inspector. It analyzes file details locally in the browser without uploading anything to a server.

## Live demo

https://shadowstrikers.github.io/metatrace/

## Features

- Drag-and-drop file upload
- EXIF and image metadata inspection
- GPS coordinate extraction and map preview
- PDF, Office, and audio metadata support
- Metadata stripping for supported image formats
- JSON export for reports

## Privacy

Everything runs client-side in the browser. No files are uploaded anywhere.
